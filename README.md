# دستیار عادل — پروژه اندرویدی (اسکلت اولیه)

این یک پروژه‌ی واقعی و native اندرویدی است (Kotlin + Jetpack Compose)، نه یک وب‌اپ.
در این مرحله فقط **صفحه‌ی اصلی و منوهای کاری/مالی** ساخته شده؛ بقیه‌ی قابلیت‌ها قدم‌به‌قدم اضافه می‌شوند.

## ساختار فعلی
- صفحه اصلی: دو کارت «کاری» و «مالی»
- کاری → تونل / آزاد / تسک‌ها (فعلاً جای‌نگه‌دار — به‌زودی تکمیل می‌شود)
- مالی → تونل / آزاد / مطالبات کلی (فعلاً جای‌نگه‌دار — به‌زودی تکمیل می‌شود)

## چطور کاملاً از گوشی، بدون Android Studio، APK بسازم؟

این پروژه یک فایل خودکارساز (`.github/workflows/build.yml`) داره که کامپایل رو روی سرورهای GitHub انجام می‌ده. مراحل با گوشی:

1. اپ **GitHub** رو از گوگل‌پلی نصب کن و یک حساب بساز (رایگان).
2. یک ریپازیتوری جدید (Repository) بساز، مثلاً به اسم `AdelAssistant`.
3. تمام فایل‌های داخل این زیپ رو (با همون ساختار پوشه‌ها) به ریپازیتوری آپلود کن.
   - راحت‌ترین راه از گوشی: اپ **Working Copy** یا **Termux + git** یا حتی آپلود مستقیم فایل از طریق سایت github.com در مرورگر گوشی (بخش Add file → Upload files، و zip رو باید از حالت فشرده خارج کنی چون گیت‌هاب مستقیم zip رو باز نمی‌کنه — این کار با یک اپ File Manager که «Extract» داره روی گوشی شدنیه).
4. به محض آپلود (push)، تب **Actions** توی گیت‌هاب رو باز کن — می‌بینی که «Build APK» به‌صورت خودکار شروع شده.
5. چند دقیقه صبر کن تا سبز بشه (✅)، بعد روش بزن و از پایین صفحه فایل `app-debug-apk` رو دانلود کن.
6. فایل دانلودی یک zip حاوی APK هست؛ اون رو Extract کن و APK رو نصب کن (لازمه «نصب از منابع ناشناس» رو در تنظیمات گوشی فعال کنی).

بعد از این مرحله، هر بار که من کد جدید (قابلیت بعدی) رو بهت بدم، فقط کافیه فایل‌های جدید رو جایگزین/آپلود کنی و همین ربات خودش دوباره APK جدید می‌سازه — بدون نیاز به کامپیوتر.

### راه جایگزین (اگر به کامپیوتر دسترسی موقت داشتی)
اگه یه بار به کامپیوتر دسترسی داشته باشی، نصب Android Studio و باز کردن پروژه هم کار می‌کنه (Open an existing project → Sync → Run) — ولی چون ترجیحت گوشیه، روش بالا رو دنبال کن.

## مرحله بعد
هر بار که یک قابلیت (مثلاً «تسک‌ها» یا «ثبت پروژه») تکمیل بشه:
- یک فایل Kotlin جدید توی `ui/` اضافه می‌شه
- در `AppNavigation.kt`، `PlaceholderScreen` مربوطه با صفحه‌ی واقعی جایگزین می‌شه
